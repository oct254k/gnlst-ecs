# 09. 모임 레이더 (Meeting Radar)

**관련 프로세스**: [process/proc_06_meeting_radar.md](../process/proc_06_meeting_radar.md)

참석자를 선택하면 각 임원의 일정을 자동으로 불러와 시간대별 충돌을 계산하고, 가능한 슬롯을 시각적으로 표시하는 기능.

---

## RAD-001: 참석자 선택 UI

| 항목 | 내용 |
|------|------|
| **기능 ID** | RAD-001 |
| **기능명** | 참석자 선택 UI |
| **버전** | 1.0 |

### 설명

모임 레이더 화면 진입 시 전체 임원 목록을 체크박스 리스트로 표시한다. 사용자가 참석 대상 임원을 선택하면 선택 상태를 저장하고, 날짜 범위 선택과 함께 RAD-002 충돌 계산 엔진을 트리거한다.

### 사전 조건

- 로그인 완료 (세션 유효)
- 임원 목록 데이터 존재
- 모임 레이더 페이지 접근 권한 보유

### 입력값

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 선택된 임원 목록 | 임원 ID 배열 | 필수 | 참석 대상으로 선택된 임원 |
| 조회 시작일 | 일자 | 필수 | 조회 기간 시작 |
| 조회 종료일 | 일자 | 필수 | 조회 기간 종료 (최대 30일) |

### 처리 흐름

1. 페이지 로드 시 시스템이 임원 목록(이름, 부서)을 조회하여 표시한다
2. 사용자가 체크박스로 임원을 전체 선택 또는 개별 선택한다
3. 날짜 범위를 입력한다 (기본값: 오늘 ~ 오늘+7일)
4. "조회" 버튼을 클릭하면 선택된 임원과 날짜 범위가 RAD-002 충돌 계산 엔진으로 전달된다

### 출력

- 선택된 임원 목록 (체크 표시 포함)
- 선택 인원 수 배지 (예: `3명 선택됨`)
- "조회" 버튼 활성화 (1명 이상 선택 시)

### 예외 처리

| 예외 상황 | 처리 방법 |
|-----------|-----------|
| 임원 목록 조회 실패 | 오류 메시지 + 재시도 버튼 |
| 아무도 선택하지 않음 | "조회" 버튼 비활성화, 안내: "1명 이상 선택하세요" |
| 날짜 범위 30일 초과 | 입력 즉시 인라인 경고: "최대 30일까지 조회 가능합니다" |
| 종료일 < 시작일 | 인라인 오류 표시, 조회 버튼 비활성화 |

연계 기능: RAD-002 (충돌 계산 엔진)

## RAD-002: 일정 충돌 계산 엔진

| 항목 | 내용 |
|------|------|
| **기능 ID** | RAD-002 |
| **기능명** | 일정 충돌 계산 엔진 |
| **버전** | 1.0 |

### 설명

선택된 임원들의 일정 데이터를 조회한 뒤, 시간대별 가용성을 계산한다. 조회 기간 내 업무 시간(09:00~18:00, 평일)을 1시간 단위 슬롯으로 나누고, 각 슬롯에서 임원별 기존 일정과 겹치는지 판정하여 가용/부분/불가 상태를 분류한다.

### 사전 조건

- RAD-001에서 선택된 임원 목록과 날짜 범위가 유효하게 전달됨
- 해당 임원들의 일정 데이터 존재

### 입력값

| 필드 | 타입 | 설명 |
|------|------|------|
| 선택된 임원 목록 | 임원 ID 배열 | 참석 대상 임원 |
| 조회 기간 | 시작일~종료일 | 조회 범위 |
| 슬롯 단위 | 분 (기본값: 60) | 시간 슬롯 분할 단위 |

### 처리 흐름

1. 선택된 임원들의 조회 기간 내 일정을 모두 조회한다 (종일 일정 포함)
2. 조회 기간 내 업무 시간(09:00~18:00, 평일)을 슬롯 단위로 분할하여 슬롯 목록을 생성한다
3. 각 슬롯에 대해 임원별로 기존 일정과 시간이 겹치는지 판정한다
4. 슬롯별 충돌 임원 수를 집계하여 상태를 분류한다 (RAD-003 상태 기준)
5. 슬롯별 결과 배열을 RAD-003으로 전달한다

### 충돌 상태 분류 기준

| 상태 | 조건 |
|------|------|
| 가용 (AVAILABLE) | 충돌 임원 수 = 0 (전원 참석 가능) |
| 부분 (PARTIAL) | 0 < 충돌 임원 수 < 전체 (일부 임원에게 기존 일정 있음) |
| 불가 (UNAVAILABLE) | 충돌 임원 수 = 전체 (전원 불가) |

### 예외 처리

| 예외 상황 | 처리 방법 |
|-----------|-----------|
| 일정 조회 실패 | 오류 상태 반환, 재시도 안내 |
| 조회 결과 0건 (일정 없음) | 전 슬롯 가용(AVAILABLE) 처리 |
| 종료 시각이 시작 시각보다 앞선 비정상 일정 | 해당 레코드 무시 후 경고 기록 |
| 시간대 불일치 | 모든 일시를 한국 표준시(KST) 기준으로 정규화 후 처리 |

연계 기능: RAD-001 (참석자 선택), RAD-003 (가능 슬롯 표시)

## RAD-003: 가능 슬롯 표시

| 항목 | 내용 |
|------|------|
| **기능 ID** | RAD-003 |
| **기능명** | 가능 슬롯 표시 (상태 아이콘 표시) |
| **버전** | 1.0 |

### 설명

RAD-002에서 계산된 슬롯 결과를 날짜×시간 격자 형태로 표시한다. 각 셀에 상태 아이콘과 함께 가용 인원 수를 표시한다.

### 상태 정의

| 상태 | 아이콘 | 조건 | 배경색 | 설명 |
|------|--------|------|--------|------|
| AVAILABLE | ✅ | 충돌 임원 수 = 0 | 녹색 | 전원 참석 가능 |
| PARTIAL | 🟡 | 0 < 충돌 임원 수 < 전체 | 노란색 | 일부 임원에게 기존 일정 있음 |
| UNAVAILABLE | ❌ | 충돌 임원 수 = 전체 | 빨간색 | 전원 불가 |

### 사전 조건

- RAD-002 계산 완료

### 입력값

| 필드 | 타입 | 설명 |
|------|------|------|
| 슬롯 결과 목록 | 슬롯 배열 | RAD-002 계산 결과 |
| 선택된 임원 정보 | 임원 배열 | 이름 표시용 |

### 처리 흐름

1. 슬롯 결과를 날짜별로 그룹화한다
2. 날짜 헤더 × 시간 축 격자를 렌더링한다
3. 각 셀에 상태 아이콘과 가용 인원 수를 표시한다 (예: ✅ 3/3, 🟡 2/3, ❌ 0/3)
4. 셀 호버 시 툴팁으로 충돌 임원 이름 목록을 표시한다
5. 셀 클릭 시 RAD-004로 연동된다 (AVAILABLE / PARTIAL 슬롯만 클릭 가능)

### 출력

- 날짜×시간 격자 테이블
- 각 셀: 상태 아이콘 + 가용 인원 수 (예: `✅ 3/3`)
- 호버 툴팁: 충돌 임원명 목록
- 범례: ✅ 전원 가능 / 🟡 일부 일정 있음 / ❌ 불가

### 격자 스크롤 처리 규칙

날짜×시간 격자가 넓어질 때 한눈에 파악할 수 있도록 헤더를 고정한다.

| 요소 | 처리 방식 |
|------|---------|
| 시간 컬럼 (첫 번째 열) | `position: sticky; left: 0` — 가로 스크롤 시 시간 축 고정 |
| 날짜 헤더 행 | `position: sticky; top: 0` — 세로 스크롤 시 날짜 고정 |
| 모바일 기본 날짜 범위 | 7일 → **5일(평일)**로 축소, 슬라이드 네비게이션으로 이전/다음 5일 이동 가능 |

### 예외 처리

| 예외 상황 | 처리 방법 |
|-----------|-----------|
| 업무 시간 내 슬롯 0개 | "해당 기간에 조회 가능한 시간대가 없습니다" 빈 상태 표시 |
| 전 슬롯 ❌ | 상단 안내: "선택된 기간에 전원 가능한 시간이 없습니다" |
| 모바일 화면 | 격자를 가로 스크롤 가능한 테이블로 처리 (sticky 규칙 동일 적용) |

연계 기능: RAD-002 (데이터 소스), RAD-004 (슬롯 선택)

## RAD-004: 슬롯 선택 → 일정 등록 연동

| 항목 | 내용 |
|------|------|
| **기능 ID** | RAD-004 |
| **기능명** | 슬롯 선택 → 일정 등록 연동 |
| **버전** | 1.0 |

### 설명

RAD-003 격자에서 가용(AVAILABLE) 또는 부분(PARTIAL) 슬롯을 클릭하면, 해당 시간 정보가 자동으로 일정 등록 폼에 채워진 상태로 등록 모달이 열린다.

### 사전 조건

- RAD-003에서 슬롯 격자가 표시된 상태
- 클릭된 슬롯의 상태가 AVAILABLE 또는 PARTIAL

### 입력값

| 필드 | 타입 | 설명 |
|------|------|------|
| 선택된 슬롯 정보 | 슬롯 | 클릭된 슬롯의 시작/종료 시각, 상태 |
| 선택된 임원 목록 | 임원 ID 배열 | 일정 참석자 자동 입력용 |

### 처리 흐름

1. 슬롯 셀을 클릭한다 (불가 슬롯은 클릭 무시)
2. 일정 등록 모달이 열린다. 시작/종료 시각과 참석자가 자동으로 채워진다
3. 부분(PARTIAL) 슬롯인 경우 모달 상단에 경고 배너를 표시한다: "{충돌 임원 수}명에게 기존 일정이 있습니다. 계속 등록하시겠습니까?"
4. 사용자가 나머지 필드를 입력 후 저장하면 일반 일정 등록 흐름(SCH-001)과 동일하게 처리된다

### 출력

- 일정 등록 모달 (시작/종료 시각, 참석자 자동 채워짐)
- PARTIAL 슬롯 경고 배너

### 예외 처리

| 예외 상황 | 처리 방법 |
|-----------|-----------|
| 불가(UNAVAILABLE) 셀 클릭 | 무시 (클릭 불가 처리) |
| 모달 열기 중 권한 오류 | 오류 메시지 표시 |
| 등록 완료 후 | 모달 닫기 → 레이더 화면으로 복귀, 결과 재계산 |

연계 기능: RAD-003 (슬롯 격자), 일정 등록 (SCH-001)
