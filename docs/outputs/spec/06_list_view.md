# 기능명세서: 리스트 뷰 (List View)

**관련 프로세스**: [process/proc_03_schedule.md](../process/proc_03_schedule.md) (일정 도메인 일부)

## 컬럼 정의

리스트 뷰의 테이블은 아래 컬럼으로 구성된다.

| 컬럼 ID | 컬럼명 | 데이터 타입 | 너비 | 정렬 | 필수 | 비고 |
|---------|--------|-------------|------|------|------|------|
| `date` | 날짜 | 날짜 | 120px | 좌 | Y | `YYYY.MM.DD (요일)` 포맷 |
| `timeSlot` | 시간대 | 문자열 | 100px | 중앙 | N | `오전` / `오후` / `종일` |
| `actualTime` | 실제 시간 | 문자열 | 140px | 중앙 | N | `HH:mm ~ HH:mm` 포맷 |
| `title` | 일정 내용 | 문자열 | flex | 좌 | Y | 검색 대상, 인라인 편집 가능 |
| `location` | 장소·파트너 | 문자열 | 200px | 좌 | N | 장소명 또는 참석 기관명 |
| `executive` | 담당자 | 문자열[] | 160px | 좌 | Y | 임원명 목록, 색상 도트 표시 |
| `type` | 구분 | 문자열 | 80px | 중앙 | Y | `개인` / `공통` 배지 |

### 컬럼 렌더링 규칙

텍스트 오버플로우 및 헤더 고정에 관한 공통 규칙.

| 컬럼 | 오버플로우 처리 | 비고 |
|------|----------------|------|
| `title` | 줄 바꿈 허용 (flex 크기) | — |
| `location` | `text-overflow: ellipsis` + hover tooltip | HTML `title` 속성으로 전체 텍스트 노출 |
| `executive` | 임원 칩 최대 **2개** 표시 후 `+n명` 배지 | `+n명` 배지 hover 시 전체 임원 목록 tooltip |
| 헤더 행 전체 | `position: sticky; top: 0` | 대량 스크롤 중 컬럼 식별 보장 |

## 필터 조합 가능 여부

각 필터는 독립적으로 동작하며, 복수 필터는 AND 조건으로 결합된다.

| 필터 | 단독 사용 | 키워드와 조합 | @멘션과 조합 | 날짜범위와 조합 | 담당자와 조합 |
|------|-----------|----------------|--------------|----------------|--------------|
| 키워드 검색 | O | — | O | O | O |
| @멘션 필터 | O | O | — | O | O |
| 날짜 범위 | O | O | O | — | O |
| 담당자 필터 | O | O | O | O | — |

> **예시**: 키워드 "회의" + 담당자 "임원A" + 날짜범위 "2026-05-01 ~ 2026-05-31" → 세 조건 모두 만족하는 일정만 표시

## LIS-001: 리스트 테이블 조회

| 항목 | 내용 |
|------|------|
| **기능 ID** | LIS-001 |
| **기능명** | 리스트 테이블 조회 |
| **설명** | 일정 데이터를 날짜 오름차순으로 정렬하여 테이블 형태로 표시한다. 날짜·시간대·실제시간·일정내용·장소·파트너 컬럼으로 구성된다. |
| **사전조건** | - 일정 데이터 조회 정상<br>- 테이블 컬럼 설정 완료 |
| **입력값** | - 일정 목록<br>- 적용된 필터 조건 (초기값: 전체 조회)<br>- 정렬 설정 (필드, 오름차순/내림차순) |

### 처리 흐름

1. 전체(또는 현재 적용된 필터 조건) 일정 목록을 조회한다.
2. 날짜 오름차순으로 정렬한다.
3. 활성화된 임원 필터 상태와 연동하여 표시 임원 일정을 필터링한다.
4. 테이블을 렌더링한다.
   - 날짜가 동일한 행은 날짜 셀을 그룹 헤더로 묶어 표시
   - 공통 일정 행: 배경색 연한 빨강 (`#FFF5F5`), [공통] 배지 표시
   - 임원 컬럼: 색상 도트 + 임원명
5. 50건 단위 페이지네이션을 적용한다 (무한 스크롤 또는 페이지 버튼).
6. 컬럼 헤더 클릭 시 정렬 방향을 전환한다 (오름차순 ↔ 내림차순).

### 날짜 그룹 표시 방식

```
┌─────────────────┬──────────┬──────────────┬──────────────────────┬─────────────┬──────────┐
│ 날짜            │ 시간대   │ 실제 시간    │ 일정 내용            │ 장소·파트너 │ 담당자   │
├─────────────────┼──────────┼──────────────┼──────────────────────┼─────────────┼──────────┤
│ 2026.05.11 (월) │ 오전     │ 09:00~10:00  │ 임원회의             │ 본사 3층    │ ● 임원A  │
│                 │ 오후     │ 14:00~15:30  │ 고객사 미팅 [공통]   │ 고객사 본부 │ 전체     │
│ 2026.05.12 (화) │ 종일     │ —            │ 어린이날             │ —           │ —        │
└─────────────────┴──────────┴──────────────┴──────────────────────┴─────────────┴──────────┘
```

| 출력 | 설명 |
|------|------|
| 테이블 | 전체 일정 리스트 |
| 날짜 그룹 | 동일 날짜 행 묶음 표시 |
| 정렬 | 컬럼 헤더 클릭으로 정렬 |
| 페이지네이션 | 50건 단위 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 조회 결과 없음 | "일정이 없습니다" 빈 상태 메시지 |
| 데이터 조회 오류 | 오류 메시지 + 재시도 버튼 |
| 대량 데이터 (1000건+) | 가상 스크롤 적용으로 성능 보장 |

## LIS-002: 빠른 입력 (테이블 내 인라인 폼)

| 항목 | 내용 |
|------|------|
| **기능 ID** | LIS-002 |
| **기능명** | 빠른 입력 |
| **설명** | 리스트 뷰 내 테이블 최하단(또는 날짜 그룹 하단)에 빠른 입력 행을 제공한다. 최소 정보(날짜, 일정내용)만으로 즉시 등록 가능하다. |
| **사전조건** | - 사용자 로그인 상태<br>- 쓰기 권한 보유 |
| **입력값** | - 날짜 (필수)<br>- 일정 내용 (필수, 최대 200자)<br>- 시간대 (선택: 오전/오후/종일)<br>- 실제 시간 (선택, HH:mm~HH:mm)<br>- 장소 (선택)<br>- 담당 임원 (필수, 1명 이상 선택) |

### 처리 흐름

1. 테이블 하단 "+ 일정 추가" 행 또는 버튼을 클릭한다.
2. 인라인 입력 행이 슬라이드 다운 애니메이션으로 펼쳐진다.
3. 날짜 입력 필드로 포커스가 자동 이동한다.
4. 필드를 입력한다.
   - 날짜: 날짜 선택 팝업
   - 시간대: 드롭다운 (오전/오후/종일)
   - 실제 시간: HH:mm~HH:mm 형식 입력
   - 일정 내용: 텍스트 입력 (최대 200자)
   - 장소: 텍스트 입력 (선택)
   - 담당자: 임원 다중 선택 드롭다운
5. Enter 키 또는 "저장" 버튼 클릭 시 일정 저장을 요청한다.
6. 저장 성공 시 입력 행이 초기화되고, 저장된 행이 1.5초간 하이라이트된다.
7. ESC 키 입력 시 입력 내용이 취소되고 행이 닫힌다.

### 유효성 검사

| 필드 | 규칙 | 오류 메시지 |
|------|------|------------|
| 날짜 | 필수, 유효한 날짜 | "날짜를 선택해주세요" |
| 일정 내용 | 필수, 1자 이상 200자 이하 | "일정 내용을 입력해주세요" |
| 실제 시간 | 시작 < 종료 | "종료 시간이 시작 시간보다 빨라야 합니다" |
| 담당자 | 1명 이상 선택 | "담당자를 선택해주세요" |

| 출력 | 설명 |
|------|------|
| 저장 성공 | 테이블에 새 행 즉시 추가, 하이라이트 |
| 저장 실패 | 인라인 오류 메시지, 입력값 유지 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 중복 일정 | 경고 토스트 표시 후 저장 허용 (중복 차단 없음) |
| 네트워크 오류 | "저장에 실패했습니다. 다시 시도해주세요" |

## LIS-003: 키워드 검색

| 항목 | 내용 |
|------|------|
| **기능 ID** | LIS-003 |
| **기능명** | 키워드 검색 |
| **설명** | 검색창에 키워드를 입력하면 일정 내용, 장소·파트너 필드에서 부분 일치 검색을 수행하고 결과를 테이블에 표시한다. |
| **사전조건** | - 리스트 뷰 로드 완료 |
| **입력값** | - 검색어 (최소 1자) |

### 처리 흐름

1. 검색창 입력을 감지한다.
2. 입력 멈춤 후 잠시 대기한 뒤 검색을 실행한다 (빠른 타이핑 중 불필요한 검색 방지).
3. 다음 필드에서 부분 일치 검색을 수행한다.
   - 일정 내용
   - 장소·파트너
4. 검색어는 대소문자를 무시하고, 앞뒤 공백은 제거하여 처리한다.
5. 결과 테이블을 업데이트한다 (기존 정렬 유지).
6. 매칭 텍스트를 하이라이트 표시한다.
7. 검색창 X 버튼 클릭 시 검색을 초기화한다.
8. 다른 필터와 AND 조건으로 결합된다 (필터 조합 표 참조).

| 출력 | 설명 |
|------|------|
| 필터링된 테이블 | 키워드 일치 행만 표시 |
| 하이라이트 | 매칭 텍스트 강조 |
| 결과 건수 | "n건의 일정" 표시 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 검색 결과 없음 | "검색 결과가 없습니다" 빈 상태 메시지 |
| 특수문자 입력 | 안전하게 처리하여 검색 오류 방지 |

## LIS-004: @멘션 필터

| 항목 | 내용 |
|------|------|
| **기능 ID** | LIS-004 |
| **기능명** | @멘션 필터 |
| **설명** | 검색창에 `@임원명`을 입력하거나 멘션 전용 필터를 사용하여 특정 임원이 포함된 일정만 필터링한다. |
| **사전조건** | - 임원 목록 데이터 로드 완료 |
| **입력값** | - `@` 제외한 임원명 또는 임원 식별자 |

### 처리 흐름

1. 검색창에서 '@' 입력을 감지하면 임원 목록 자동완성 드롭다운을 표시한다.
2. 추가 입력으로 임원명을 필터링한다.
3. 선택 시 @태그 형태로 검색창에 삽입된다.
4. (또는) 필터 바의 "@멘션" 드롭다운에서 직접 임원을 선택한다.
5. 선택된 임원이 담당자로 포함된 일정만 표시한다.
6. 복수 @멘션 지원: @임원A @임원B → OR 조건
7. @멘션 태그 X 버튼으로 개별 해제 가능하다.

### 자동완성 표시 형식

```
@임 입력 시:
┌─────────────────┐
│ ● 임원A (파란)  │
│ ● 임원B (주황)  │
└─────────────────┘
```

| 출력 | 설명 |
|------|------|
| 필터링된 테이블 | 선택 임원 포함 일정만 표시 |
| @태그 배지 | 적용된 멘션 필터 배지 표시 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 존재하지 않는 임원명 | 자동완성에 "일치하는 임원 없음" |
| @멘션 전체 해제 | 전체 일정 표시 복귀 |

## LIS-005: 날짜 범위 필터

| 항목 | 내용 |
|------|------|
| **기능 ID** | LIS-005 |
| **기능명** | 날짜 범위 필터 |
| **설명** | 시작일과 종료일을 지정하여 해당 기간 내 일정만 테이블에 표시한다. |
| **사전조건** | - 리스트 뷰 로드 완료 |
| **입력값** | - 시작일 (필수)<br>- 종료일 (필수) |

### 처리 흐름

1. 필터 바에서 날짜 범위 선택 버튼을 클릭한다.
2. 달력 선택 화면에서 시작일과 종료일을 선택한다 (범위 선택).
3. 선택된 날짜 범위 내에 속하는 일정만 표시한다.
4. 빠른 선택 버튼을 제공한다.
   - 오늘 / 이번 주 / 이번 달 / 다음 달
5. 선택된 범위를 필터 바에 "YYYY.MM.DD ~ YYYY.MM.DD" 형태로 표시한다.
6. X 버튼으로 날짜 범위 필터를 초기화한다.

### 빠른 선택 옵션

| 버튼 | 범위 |
|------|------|
| 오늘 | 오늘~오늘 |
| 이번 주 | 이번 주 일요일~토요일 |
| 이번 달 | 1일~말일 |
| 다음 달 | 다음달 1일~말일 |

| 출력 | 설명 |
|------|------|
| 필터링된 테이블 | 날짜 범위 내 일정만 표시 |
| 범위 배지 | 필터 바에 적용된 범위 표시 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 시작일 > 종료일 | "시작일은 종료일보다 앞서야 합니다" 경고 |
| 범위 내 일정 없음 | "해당 기간에 일정이 없습니다" |

## LIS-006: 담당자 필터

| 항목 | 내용 |
|------|------|
| **기능 ID** | LIS-006 |
| **기능명** | 담당자 필터 |
| **설명** | 임원(담당자)을 선택하여 해당 임원이 포함된 일정만 표시한다. 복수 선택 시 OR 조건으로 동작한다. |
| **사전조건** | - 임원 목록 로드 완료 |
| **입력값** | - 선택된 임원 목록 |

### 처리 흐름

1. 필터 바에서 "담당자" 드롭다운을 클릭한다.
2. 임원 목록 드롭다운을 표시한다 (색상 도트 + 임원명).
3. 체크박스로 복수 선택이 가능하다.
4. 선택 즉시 테이블 필터링이 적용된다.
5. 선택된 임원이 담당자 목록에 하나라도 포함된 일정을 표시한다 (OR 조건).
6. "전체" 선택 시 필터가 해제된다.
7. 선택된 임원 배지를 필터 바에 표시하고, X 버튼으로 개별 해제할 수 있다.

> **@멘션 필터(LIS-004)와의 차이**: @멘션은 검색창 입력 방식, 담당자 필터는 드롭다운 선택 방식. 동시에 적용 시 AND 조건으로 결합.

| 출력 | 설명 |
|------|------|

## LIS-007: 인라인 수정 (행 클릭 → 편집 모드)

| 항목 | 내용 |
|------|------|
| **기능 ID** | LIS-007 |
| **기능명** | 인라인 수정 |
| **설명** | 리스트 뷰 테이블의 행을 클릭하면 해당 행이 편집 모드로 전환된다. 필드를 수정하고 저장할 수 있다. |
| **사전조건** | - 사용자 로그인 상태<br>- 수정 권한 보유 (본인 일정 또는 관리자) |
| **입력값** | - 수정할 일정 식별자<br>- 수정된 필드값 |

### 처리 흐름

1. 테이블 행 클릭을 감지한다.
2. 해당 행이 편집 모드로 전환된다.
   - 텍스트 셀 → 입력 필드로 교체
   - 날짜 셀 → 날짜 선택기
   - 시간 셀 → 시간 입력
   - 담당자 셀 → 다중 선택 드롭다운
   - 구분(개인/공통) 셀 → 드롭다운
3. 다른 행 클릭 시 현재 편집 중인 행의 저장 여부 확인 모달을 표시한다.
   - "저장" → 저장 후 다음 행 편집
   - "취소" → 변경 내용 되돌리기 후 다음 행 편집
4. "저장" 버튼 클릭 또는 Enter 키 입력 시:
   - 유효성 검사 실행 (LIS-002 동일 규칙)
   - 일정 저장을 요청한다.
   - 성공 시 편집 모드 해제, 행 데이터 갱신
5. ESC 키 입력 시 변경 내용이 취소되고 편집 모드가 해제된다.
6. 편집 중인 행의 배경색이 변경된다 (`#FFFDE7` 연노랑).

### 편집 모드 행 상태

```
편집 전:
│ 2026.05.11 │ 오전 │ 09:00~10:00 │ 임원회의 │ 본사 3층 │ ● 임원A │

편집 후 (편집 모드):
│ [날짜피커] │ [시간대▼] │ [시간입력] │ [임원회의___] │ [장소___] │ [임원멀티▼] │ [저장] [취소] │
```

### 권한 제어

| 역할 | 수정 가능 범위 |
|------|--------------|
| 일반 사용자 | 본인이 담당자인 일정 |
| 관리자 | 전체 일정 |
| 읽기 전용 | 수정 불가, 행 클릭 시 상세 보기 모달만 오픈 |

| 출력 | 설명 |
|------|------|
| 편집 모드 행 | 인라인 입력 필드로 전환 |
| 저장 성공 | 행 데이터 즉시 갱신 |
| 저장 실패 | 인라인 오류 메시지, 입력값 유지 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 권한 없는 행 클릭 | 편집 모드 미전환, "수정 권한이 없습니다" 툴팁 |
| 저장 중 다른 행 클릭 | 저장 여부 확인 모달 표시 |
| 동시 수정 충돌 | "다른 사용자가 수정 중입니다" 경고 후 최신 데이터 로드 |
