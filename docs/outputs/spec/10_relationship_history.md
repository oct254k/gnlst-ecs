# 10. 관계 히스토리 (Relationship History)

**관련 프로세스**: [process/proc_07_relationship_history.md](../process/proc_07_relationship_history.md)

일정 목록에서 @회사 또는 @사람 태그를 클릭하면 해당 주체와의 미팅 히스토리를 카드 형태로 표시하는 기능.

---

## 공통 UI 상세

### 카드 표시 사양

| 항목 | 값 |
|------|-----|
| 카드 형태 | 팝오버 (데스크탑) / 바텀 시트 (모바일, <768px) |
| 카드 너비 | 360px (데스크탑 고정) / 화면 너비 100% (모바일) |
| 카드 최대 높이 | 480px (초과 시 미팅 목록 영역 내부 스크롤) |
| 미팅 목록 표시 건수 | 최대 10건 (스크롤 컨테이너) |
| 표시 위치 (데스크탑) | 클릭한 태그 기준 우측·하단 우선 배치, 화면 끝 초과 시 반대 방향으로 자동 전환 |
| 표시 위치 (모바일) | 화면 하단에서 슬라이드업, 배경 디머 처리 |
| 닫기 인터랙션 | [×] 버튼, 외부 클릭, ESC 키 (모바일은 바텀 시트 스와이프 다운 추가) |
| 트리거 영역 | 일정 목록·일정 상세·일정 등록 폼 내의 @회사/@사람 태그 |

### 상태별 표시

| 상태 | 트리거 조건 | UI 표시 |
|------|------------|--------|
| 로딩 (loading) | REL-002 조회 호출 후 응답 대기 | 카드 즉시 열림, 요약·목록 영역에 스켈레톤 UI (회색 막대) 표시 |
| 정상 (loaded) | REL-002 응답 정상 수신, 미팅 1건 이상 | 요약 섹션 + 미팅 목록 (날짜 내림차순, 최대 10건) |
| 빈 상태 (empty) | REL-002 응답 정상, 미팅 0건 | "아직 미팅 이력이 없습니다" 빈 상태 메시지, 요약 수치는 0 표기 |
| 오류 (error) | REL-002 네트워크/서버 오류 | 카드 내 "이력을 불러오지 못했습니다" 메시지 + [재시도] 버튼 |
| 닫힘 (closed) | 외부 클릭·ESC·동일 태그 재클릭 | 카드 제거, 트리거 태그 포커스 복귀 |

### 접근성

- 카드 열림 시 `role="dialog"` 또는 `role="tooltip"` 부여 (모바일 바텀 시트는 `dialog`)
- ESC 키로 닫기 가능
- 닫힌 후 포커스는 트리거한 태그로 복귀
- 미팅 행은 `role="link"` 또는 `<a>`로 마크업하여 키보드 탐색 지원

## 히스토리 카드 필드 정의

| 필드명 | 표시 레이블 | 타입 | 설명 |
|--------|------------|------|------|
| `entity_type` | 구분 | 코드(회사/사람) | @회사 또는 @사람 |
| `entity_name` | 이름 | 문자열 | 회사명 또는 사람 이름 |
| `total_count` | 총 미팅 횟수 | 숫자 | 전체 기간 누적 미팅 수 |
| `latest_date` | 최근 미팅 날짜 | 일자 | 가장 최근 미팅 날짜 |
| `latest_manager` | 최근 담당자 | 문자열 | 최근 미팅 담당 임원 이름 |
| `meetings` | 미팅 목록 | 목록 | 날짜순 정렬된 미팅 배열 |

#### 미팅 항목 상세 필드

| 필드명 | 타입 | 설명 |
|--------|------|------|
| 일정 ID | 식별자 | 일정 고유 식별자 |
| 미팅 날짜 | 일자 | 미팅 시작 날짜 |
| 담당 임원 이름 | 문자열 | 담당 임원 이름 |
| 장소 | 문자열 | 장소 (없으면 빈값) |
| 제목 | 문자열 | 미팅 제목 |

## REL-001: 관계 히스토리 카드 트리거

| 항목 | 내용 |
|------|------|
| **기능 ID** | REL-001 |
| **기능명** | 관계 히스토리 카드 트리거 (@회사/@사람 클릭) |
| **버전** | 1.0 |

### 설명

일정 목록, 일정 상세, 일정 등록 폼 등 @회사/@사람 태그가 표시되는 모든 위치에서 해당 태그를 클릭하면 REL-002 히스토리 조회를 실행하고, 결과를 REL-003 카드로 표시한다.

### 사전 조건

- 로그인 완료 (세션 유효)
- 일정 데이터에 회사 또는 담당자 정보가 존재

### 입력값

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 태그 유형 | 코드(회사/사람) | 필수 | 클릭된 태그 유형 |
| 태그 이름 | 문자열 | 필수 | 클릭된 회사명 또는 사람 이름 |

### 처리 흐름

1. @회사 또는 @사람 태그를 클릭한다
2. 태그 유형과 이름을 추출한다
3. 클릭 위치 기준으로 카드 표시 위치를 계산한다 (화면 끝 초과 시 반대 방향으로 전환)
4. 로딩 표시 후 REL-002 조회를 호출한다
5. 조회 완료 시 REL-003 카드를 렌더링한다
6. 카드 외부 클릭 또는 ESC 키 입력 시 카드를 닫는다

### 출력

- 팝오버 형태의 히스토리 카드 (REL-003)
- 로딩 중: 스켈레톤 UI

### 예외 처리

| 예외 상황 | 처리 방법 |
|-----------|-----------|
| 미팅 이력 0건 | 카드 내 "아직 미팅 이력이 없습니다" 빈 상태 표시 |
| 조회 오류 | 카드 내 오류 메시지 + 재시도 버튼 |
| 동일 태그 재클릭 | 카드 토글 (열려있으면 닫기) |
| 다른 태그 클릭 | 이전 카드 닫고 새 카드 열기 |

연계 기능: REL-002 (데이터 조회), REL-003 (카드 UI)

## REL-002: 미팅 히스토리 조회

| 항목 | 내용 |
|------|------|
| **기능 ID** | REL-002 |
| **기능명** | 미팅 히스토리 조회 |
| **버전** | 1.0 |

### 설명

REL-001에서 전달받은 태그 유형과 이름으로 일정 데이터를 조회하여 미팅 목록, 총 횟수, 최근 담당자를 집계한다.

### 사전 조건

- 태그 유형, 태그 이름 유효 값 전달
- 일정 데이터에 회사명, 담당자, 담당 임원, 장소, 시작 일시 정보 존재

### 입력값

| 필드 | 타입 | 설명 |
|------|------|------|
| 태그 유형 | 코드(회사/사람) | 조회 유형 |
| 태그 이름 | 문자열 | 회사명 또는 사람 이름 (정확히 일치) |

### 처리 흐름

1. 태그 유형에 따라 검색 대상 필드를 결정한다 (회사 → 회사 필드, 사람 → 담당자 필드)
2. 해당 이름과 일치하는 일정 목록을 날짜 내림차순으로 조회한다 (담당 임원 이름 포함)
3. 총 미팅 횟수, 최근 미팅 날짜, 최근 담당자를 집계한다
4. 결과를 히스토리 카드 데이터로 조합하여 반환한다

### 출력

히스토리 카드 데이터:
- 태그 유형, 이름
- 총 미팅 횟수
- 최근 미팅 날짜
- 최근 담당자 이름
- 미팅 목록 (날짜 내림차순)

### 예외 처리

| 예외 상황 | 처리 방법 |
|-----------|-----------|
| 조회 결과 0건 | 총 횟수 0, 빈 목록 반환 (오류 아님) |
| 네트워크 오류 | 오류 상태 반환, 호출자(REL-001)에서 처리 |
| 이름 값이 빈 문자열 | 조회 생략, 즉시 빈 결과 반환 |

연계 기능: REL-001 (트리거), REL-003 (카드 표시)

## REL-003: 히스토리 카드 UI 표시

| 항목 | 내용 |
|------|------|
| **기능 ID** | REL-003 |
| **기능명** | 히스토리 카드 UI 표시 |
| **버전** | 1.0 |

### 설명

REL-002에서 조회된 데이터를 팝오버 카드 형태로 표시한다. 카드 상단에 요약 정보(총 횟수, 최근 날짜, 최근 담당자)를 표시하고, 하단에 미팅 목록을 날짜 내림차순으로 나열한다.

### 사전 조건

- REL-002에서 히스토리 데이터 정상 수신

### 입력값

| 필드 | 타입 | 설명 |
|------|------|------|
| 히스토리 데이터 | 객체 | REL-002 조회 결과 |
| 팝오버 기준 위치 | 좌표 | 카드 표시 기준 좌표 |

### 카드 레이아웃 구성

```
┌────────────────────────────────────┐
│  🏢 (회사명) / 👤 (사람 이름)   [×] │
│  ─────────────────────────────────  │
│  총 미팅  최근 날짜    최근 담당자   │
│   12회    2026-04-30   홍길동 전무   │
│  ─────────────────────────────────  │
│  날짜          담당자   장소         │
│  2026-04-30   홍길동    본사 회의실  │
│  2026-03-15   김영희    상대방 사무실 │
│  2026-01-10   박철수    —           │
│  ⋮                                  │
│  (최대 10건 표시, 스크롤)            │
└────────────────────────────────────┘
```

### 처리 흐름

1. 히스토리 데이터를 수신한다
2. 요약 섹션을 표시한다 (총 미팅 횟수 / 최근 미팅 날짜 / 최근 담당자)
3. 미팅 목록을 날짜 내림차순으로 표시한다 (날짜, 담당자 이름, 장소, 없으면 — 표시, 최대 10건, 초과 시 스크롤)
4. 미팅 행 클릭 시 해당 일정 상세 페이지로 이동한다
5. [×] 버튼 또는 외부 클릭 시 카드를 닫는다

### 출력

- 팝오버 히스토리 카드 (요약 + 미팅 목록)
- 이력 0건: "아직 미팅 이력이 없습니다" 빈 상태 뷰

### 예외 처리

| 예외 상황 | 처리 방법 |
|-----------|-----------|
| 장소 없음 | "—" (em dash) 표시 |
| 최근 담당자 없음 | "—" 표시 |
| 미팅 목록 10건 초과 | 카드 내 스크롤 (최대 높이 고정) |
| 모바일 화면 | 팝오버 대신 바텀 시트(Bottom Sheet)로 표시 |

연계 기능: REL-001 (트리거), REL-002 (데이터)
