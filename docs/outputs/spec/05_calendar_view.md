## CAL-001: 월간 뷰 렌더링

| 항목 | 내용 |
|------|------|
| **기능 ID** | CAL-001 |
| **기능명** | 월간 뷰 렌더링 |
| **설명** | 선택한 월(月)의 전체 일정을 달력 형태로 표시한다. 임원별 색상 레이어, 공통 일정, 공휴일이 모두 동시에 표시된다. |
| **사전조건** | - 달력 컴포넌트 초기화 완료<br>- 일정 데이터 조회 정상<br>- 공휴일 데이터 로드 완료 |
| **입력값** | - 기준 날짜 (기본값: 오늘)<br>- 임원 목록 (이름, 표시 여부)<br>- 전체 일정 목록 |

### 처리 흐름

1. 해당 월의 일정 목록을 조회한다 (기간 범위: 해당 월 시작일~종료일).
2. 임원별 체크박스 ON/OFF 상태에 따라 일정을 필터링한다.
3. 공통 일정은 별도 색상으로 강제 표시한다.
4. 공휴일 데이터를 날짜 셀에 오버레이한다 (날짜 색상 변경 + 툴팁).
5. 오늘 날짜 셀을 시각적으로 강조 표시한다.

| 출력 | 설명 |
|------|------|
| 달력 그리드 | 해당 월 전체 날짜 셀 표시 |
| 일정 이벤트 바 | 각 날짜에 임원별 색상 바로 표시 |
| 공휴일 마킹 | 공휴일 날짜 빨간 글씨 + 툴팁 |
| 오늘 날짜 | 배경색 하이라이트 |

### 월간 뷰 이벤트 오버플로우 규칙

날짜 셀 내 이벤트 바는 **최대 3개**까지만 렌더링한다. 초과 일정은 `+n개` 배지로 축약 표시하여 셀 높이 초과를 방지한다.

| 조건 | 표시 |
|------|------|
| 일정 ≤ 3개 | 전체 이벤트 바 표시 |
| 일정 > 3개 | 상위 3개 이벤트 바 + `+n개` 오버플로우 배지 |
| `+n개` 배지 클릭 | CAL-007 일 상세 패널 오픈 (기존 동작 재사용) |

> 이벤트 우선순위: 공통 일정 → 임원 개인 일정 (시간순). 공통 일정은 3개 제한에 포함되나 항상 상위에 배치.

### 예외 처리

| 상황 | 처리 |
|------|------|
| 일정 데이터 조회 실패 | "일정을 불러오지 못했습니다" 토스트 표시, 빈 달력 렌더링 |
| 일정 없는 날 | 빈 셀 표시 (오류 아님) |
| 네트워크 지연 | 로딩 스피너 표시, 10초 후 재시도 1회 |

## CAL-002: 주간 뷰 렌더링

| 항목 | 내용 |
|------|------|
| **기능 ID** | CAL-002 |
| **기능명** | 주간 뷰 렌더링 |
| **설명** | 선택한 주(週)의 7일치 시간표 형식 달력을 표시한다. 시간축(0시~24시)이 세로로 표시되며, 일정은 해당 시간 슬롯에 블록으로 배치된다. |
| **사전조건** | - 달력 컴포넌트 초기화 완료<br>- 일정에 시작 시간, 종료 시간 정보 존재 |
| **입력값** | - 해당 주 기준 날짜<br>- 임원 목록<br>- 전체 일정 목록 |

### 처리 흐름

1. 해당 주(월요일~일요일)의 일정 목록을 조회한다.
2. 30분 단위 시간 슬롯 그리드를 렌더링한다.
3. 이벤트 블록을 배치한다.
   - 시작 시간~종료 시간 높이 비례 계산
   - 동일 시간대 중복 이벤트는 좌우 분할 표시
4. 빈 시간대를 시각화한다 (CAL-009 연동).
5. 공휴일 날짜 컬럼 헤더에 색상을 적용한다.

| 출력 | 설명 |
|------|------|
| 7일 컬럼 그리드 | 각 요일별 컬럼, 시간축 표시 |
| 이벤트 블록 | 시간 비례 높이, 임원 색상 적용 |
| 빈 슬롯 | 연한 배경으로 빈 시간대 강조 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 종일 일정 | 상단 "종일" 영역에 별도 표시 |
| 시간 미지정 일정 | 종일 영역에 배치 |
| 30분 미만 이벤트 | 최소 블록 높이(30분 분량) 보장 |

## CAL-003: 일간 뷰 렌더링

| 항목 | 내용 |
|------|------|
| **기능 ID** | CAL-003 |
| **기능명** | 일간 뷰 렌더링 |
| **설명** | 특정 하루의 시간표 형식 달력을 표시한다. 주간 뷰와 동일한 시간축 구조이나 단일 날짜 컬럼으로 표시된다. |
| **사전조건** | - 달력 컴포넌트 초기화 완료 |
| **입력값** | - 표시할 날짜<br>- 임원 목록<br>- 전체 일정 목록 |

### 처리 흐름

1. 해당 날짜의 일정 목록을 조회한다.
2. 15분 단위 시간 슬롯 그리드를 렌더링한다.
3. 이벤트 블록을 배치한다 (좌우 분할로 중복 처리).
4. 현재 시각을 나타내는 표시 선을 렌더링한다.
5. 이미 일간 뷰인 상태에서 날짜를 클릭하면 상세 패널을 바로 연다 (CAL-007 연동).

| 출력 | 설명 |
|------|------|
| 단일 날짜 시간표 | 0시~24시 전체 표시 |
| 현재 시각 선 | 빨간 수평선으로 현재 시각 표시 |
| 이벤트 블록 | 시간 비례 블록 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 공휴일인 날 | 날짜 헤더에 공휴일명 툴팁 표시 |
| 일정 없는 날 | 빈 시간표 표시, "일정이 없습니다" 안내 텍스트 |

## CAL-004: 임원별 색상 레이어 ON/OFF (체크박스)

| 항목 | 내용 |
|------|------|
| **기능 ID** | CAL-004 |
| **기능명** | 임원별 색상 레이어 ON/OFF |
| **설명** | 임원 목록이 체크박스 형태로 표시되며, 체크 해제 시 해당 임원의 일정이 달력에서 숨겨진다. 각 임원은 고유 색상을 가진다. |
| **사전조건** | - 임원 목록 데이터 로드 완료<br>- 임원별 고유 색상 코드 시스템 등록 완료 |
| **입력값** | - 임원 목록 (이름, 고유 색상, 표시 여부)<br>- 체크박스 클릭 이벤트 |

### 처리 흐름

1. 사이드바/상단 패널에 임원 목록 체크박스를 렌더링한다.
   - 각 임원 항목: [색상 원] [이름] [체크박스]
2. 체크박스 클릭 시 해당 임원의 표시 상태가 토글된다.
3. 해당 임원의 일정이 달력에서 표시/숨김 전환된다.
4. ON/OFF 상태를 브라우저에 저장하여 페이지 새로고침 후에도 유지한다.
5. 공통 일정은 체크박스 영향 없이 항상 표시된다 (CAL-005 연동).

### 임원 색상 정의 예시

| 임원 | 색상 |
|--------|-----------|
| 임원 A | `#4A90D9` |
| 임원 B | `#E67E22` |
| 임원 C | `#27AE60` |
| 임원 D | `#8E44AD` |
| 공통 일정 | `#E74C3C` (별도, 항상 표시) |

| 출력 | 설명 |
|------|------|
| 체크박스 패널 | 임원별 색상 + 이름 + 체크박스 목록 |
| 달력 필터링 | ON 임원만 이벤트 표시 |
| 상태 유지 | 브라우저 기반 ON/OFF 상태 유지 (새로고침 후에도 유지) |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 전체 OFF | "표시 중인 일정이 없습니다" 안내 표시 |
| 임원 데이터 없음 | 체크박스 패널 빈 상태, 오류 없음 |

## CAL-005: 공통 일정 별도 색상 표시

| 항목 | 내용 |
|------|------|
| **기능 ID** | CAL-005 |
| **기능명** | 공통 일정 별도 색상 표시 |
| **설명** | 공통 일정(여러 임원이 공유하는 일정)은 시스템 지정 색상으로 항상 달력에 표시된다. 임원별 체크박스 ON/OFF와 무관하게 항상 가시적이어야 한다. |
| **사전조건** | - 일정 데이터에 일정 유형(공통) 정보 존재<br>- 공통 일정 색상 시스템 상수 정의 |
| **입력값** | - 일정 목록 (유형 필드 포함) |

### 처리 흐름

1. 일정 로드 시 유형이 "공통"인 일정을 분리한다.
2. 공통 일정은 별도 이벤트 소스로 관리하여 시스템 지정 색상(`#E74C3C`)으로 강제 표시한다.
3. 임원 체크박스 필터 로직에서 공통 일정은 제외하여 항상 표시 상태를 유지한다.
4. 이벤트 바에 "[공통]" 레이블 또는 아이콘을 표시한다.

### 공통 일정 시각 규칙

| 요소 | 규칙 |
|------|------|
| 배경색 | `#E74C3C` (빨강 계열, 시스템 상수) |
| 텍스트색 | `#FFFFFF` |
| 레이블 | 이벤트 바 앞에 "[공통]" 프리픽스 또는 아이콘 |
| 우선순위 | 임원 개인 일정보다 위에 표시 |

| 출력 | 설명 |
|------|------|
| 공통 일정 바 | 별도 색상, 항상 표시 |
| 레이블 | "[공통]" 프리픽스 표시 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 공통 일정과 개인 일정 동일 시간대 중복 | 공통 일정 우선 표시, 개인 일정 옆에 배치 |

## CAL-006: 공휴일 표시 (빨간 날짜 + 툴팁)

| 항목 | 내용 |
|------|------|
| **기능 ID** | CAL-006 |
| **기능명** | 공휴일 표시 |
| **설명** | 법정 공휴일 및 임시 공휴일이 등록된 날짜의 날짜 숫자를 빨간색으로 표시하고, 마우스 오버 시 공휴일 이름이 툴팁으로 나타난다. |
| **사전조건** | - 공휴일 데이터 로드 완료<br>- 달력 뷰 렌더링 완료 |
| **입력값** | - 공휴일 목록 (날짜, 이름, 유형: 법정/대체/임시) |

### 처리 흐름

1. 달력 렌더링 시 공휴일 데이터를 주입한다.
2. 각 날짜 셀에서 해당 날짜가 공휴일 목록에 포함되는지 확인한다.
3. 공휴일인 날짜: 날짜 숫자를 빨간색으로 표시한다.
4. 마우스 오버 시 공휴일명을 툴팁으로 표시한다.
   - 예: "어린이날", "대체 어린이날"
5. 주간/일간 뷰에서도 동일하게 컬럼 헤더 날짜에 적용된다.

### 툴팁 표시 규칙

| 공휴일 유형 | 툴팁 내용 |
|-------------|-----------|
| 법정 공휴일 | `{공휴일명}` |
| 대체 공휴일 | `대체 {원공휴일명}` |
| 임시 공휴일 | `임시 공휴일: {이름}` |

| 출력 | 설명 |
|------|------|
| 빨간 날짜 숫자 | 공휴일 날짜 셀의 날짜 숫자 |
| 툴팁 | 마우스 오버 시 공휴일 이름 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 공휴일 데이터 로드 실패 | 날짜 기본 색상 유지, 오류 로그 기록 |
| 동일 날짜에 복수 공휴일 | 툴팁에 줄바꿈으로 복수 표시 |

## CAL-007: 날짜 클릭 → 일 상세 펼침

| 항목 | 내용 |
|------|------|
| **기능 ID** | CAL-007 |
| **기능명** | 날짜 클릭 → 일 상세 펼침 |
| **설명** | 달력의 날짜 셀(또는 날짜 숫자)을 클릭하면 해당 날짜의 일정 상세 목록이 사이드 패널 또는 모달로 펼쳐진다. |
| **사전조건** | - 달력 뷰 렌더링 완료 |
| **입력값** | - 클릭한 날짜 |

### 처리 흐름

1. 사용자가 달력에서 날짜를 클릭한다.
2. 해당 날짜의 일정 목록을 조회하거나 캐시에서 필터링한다.
3. 일 상세 패널이 슬라이드 인 애니메이션으로 열린다.
   - 상단: 날짜 표시 (예: "2026년 5월 11일 월요일")
   - 공휴일 여부 배지 표시
   - 일정 목록: 시간순 정렬, 임원별 색상 도트
   - 일정 없을 시: "이 날 일정이 없습니다" 표시
4. 패널 외부 클릭 또는 ESC 키로 닫힌다.
5. 월간 뷰에서 날짜 클릭 시 일 상세 패널이 열린다.
6. 일간 뷰에서 이미 선택된 날짜를 다시 클릭하면 패널이 토글(닫기)된다.

### 일 상세 패널 구성

| 영역 | 내용 |
|------|------|
| 헤더 | 날짜, 요일, 공휴일 배지 |
| 일정 목록 | 시간 / 임원 색상 도트 / 일정명 / 장소 |
| 빈 상태 | "이 날 일정이 없습니다" 메시지 |
| 액션 | 닫기 버튼, 해당 일 일간 뷰로 이동 버튼 |

| 출력 | 설명 |
|------|------|
| 일 상세 패널 | 슬라이드 인 사이드 패널 |
| 일정 목록 | 해당 날짜 전체 일정 시간순 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 일정 로드 실패 | 패널 내 "불러오기 실패" 메시지 |
| 이미 패널 열린 상태에서 다른 날짜 클릭 | 패널 내용 즉시 교체 |

## CAL-008: 오늘 날짜 하이라이트

| 항목 | 내용 |
|------|------|
| **기능 ID** | CAL-008 |
| **기능명** | 오늘 날짜 하이라이트 |
| **설명** | 현재 날짜(today)에 해당하는 달력 셀을 시각적으로 강조 표시한다. 뷰 전환 및 날짜 이동 후에도 오늘 날짜는 항상 구분 가능해야 한다. |
| **사전조건** | - 달력 뷰 렌더링 완료 |
| **입력값** | - 시스템 현재 날짜 (자동 감지) |

### 처리 흐름

1. 달력 렌더링 시 오늘 날짜 셀에 시각적 강조를 적용한다.
   - 배경색: 연한 파란색 (`#EBF5FB`)
   - 날짜 숫자: 파란색 원형 배지 배경
2. 주간/일간 뷰에서도 해당 컬럼 헤더를 강조한다.
3. "오늘" 버튼 클릭 시 오늘 날짜로 달력 뷰가 이동한다.
4. 자정이 지나면 자동으로 다음 날로 오늘 날짜 표시가 갱신된다.

### 하이라이트 스타일 정의

| 뷰 | 적용 요소 | 스타일 |
|----|-----------|--------|
| 월간 | 날짜 셀 | 배경색 `#EBF5FB` |
| 월간 | 날짜 숫자 | 파란 원형 배지 |
| 주간 | 컬럼 헤더 | 하단 파란 밑줄 |
| 일간 | 날짜 헤더 | 파란 배지 |

| 출력 | 설명 |
|------|------|
| 오늘 셀 강조 | 배경색 + 날짜 숫자 배지 |
| 뷰별 강조 | 월/주/일 각 뷰에 맞는 스타일 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 다른 월 뷰에서 오늘 날짜가 화면에 없을 때 | 상단 "오늘" 버튼 항상 표시 |
| 자정 전환 감지 실패 | 다음 사용자 인터랙션 시 날짜 재계산 |

## CAL-009: 빈 시간대 시각화

| 항목 | 내용 |
|------|------|
| **기능 ID** | CAL-009 |
| **기능명** | 빈 시간대 시각화 |
| **설명** | 주간 뷰 및 일간 뷰에서 일정이 없는 시간대를 시각적으로 구분하여 사용자가 빈 시간을 한눈에 파악할 수 있도록 한다. |
| **사전조건** | - 주간 또는 일간 뷰 렌더링 완료<br>- 해당 날짜의 일정 데이터 로드 완료 |
| **입력값** | - 일정 목록 (시작/종료 시간 포함)<br>- 업무 시간대 설정 (기본: 09:00~18:00) |

### 처리 흐름

1. 업무 시간대(기본 09:00~18:00) 내 슬롯을 기준으로 분석한다.
2. 각 30분 슬롯에 일정 존재 여부를 계산한다.
3. 빈 슬롯과 업무 시간 외 슬롯에 각각 다른 배경색을 적용한다.
   - 빈 업무 시간: 연한 녹색 (`#F0FFF0`)
   - 비업무 시간: 연한 회색 (`#F5F5F5`)
4. 업무 시간 범위는 설정 페이지에서 변경 가능하다 (기본값 고정).
5. 비업무 시간대는 음영으로 처리하여 구분한다.

### 시간대 색상 규칙

| 구분 | 배경색 | 의미 |
|------|--------|------|
| 빈 업무 시간 | `#F0FFF0` (연녹색) | 일정 잡기 가능 |
| 이벤트 있는 시간 | 임원 색상 블록 | 일정 있음 |
| 비업무 시간 | `#F5F5F5` (연회색) | 업무 시간 외 |

| 출력 | 설명 |
|------|------|
| 색상 구분 슬롯 | 빈/이벤트/비업무 시간 색상 구분 |
| 빠른 인지 | 스크롤 없이 빈 시간 파악 가능 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 전체 업무 시간 이벤트로 채워진 경우 | 빈 슬롯 없음, 정상 표시 |
| 월간 뷰에서 호출 | 해당 기능 비활성화 (월간 뷰는 CAL-009 미적용) |
