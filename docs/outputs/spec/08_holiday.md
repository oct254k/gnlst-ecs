### 공휴일 (Holiday)

| 필드명 | 타입 | 필수 | 설명 |

| `created_by` | 식별자 | N | 등록자 (시스템 자동 등록 시 NULL) |

### 공휴일 유형 정의

| 유형 코드 | 유형명 | 설명 | 등록 방식 |
|-----------|--------|------|-----------|
| `statutory` | 법정 공휴일 | 관공서의 공휴일에 관한 규정 지정 공휴일 | 시스템 자동 (연간 배치) |

| `temporary` | 임시 공휴일 | 정부가 임시로 지정하는 공휴일 | 관리자 수동 등록 |

## HOL-001: 법정 공휴일 자동 등록

| 항목 | 내용 |
|------|------|
| **기능 ID** | HOL-001 |
| **기능명** | 법정 공휴일 자동 등록 |
| **설명** | 매년 초(또는 전년도 말) 해당 연도의 법정 공휴일 및 대체공휴일을 시스템이 자동으로 계산하여 데이터베이스에 등록한다. |
| **사전조건** | - 공휴일 데이터 소스(외부 API 또는 내부 계산 로직) 정상 동작<br>- 배치 실행 권한 보유 (시스템 또는 관리자) |
| **입력값** | - 등록 대상 연도<br>- 데이터 소스 선택 (HOL-004 연동) |

### 처리 흐름

1. 배치가 자동 실행된다 (매년 1월 1일 00:01 또는 관리자 수동 실행)
2. 대상 연도를 결정한다 (현재 연도 또는 다음 연도 미리 등록 지원)
3. 공휴일 데이터를 조회한다 (HOL-004 소스 우선순위에 따라 외부 공공 API 우선, 실패 시 내부 계산으로 전환)
4. 음력 공휴일(설날, 추석, 부처님 오신 날)을 음력 변환 로직으로 계산한다
5. 대체공휴일 적용 대상 공휴일에 대해 대체공휴일을 계산한다
6. 이미 등록된 해당 연도 법정/대체 공휴일을 확인하여 기존 레코드는 업데이트하고 없는 경우 신규 등록한다
7. 등록 결과를 로그에 기록한다 (성공 건수, 실패 건수, 변경 건수)
8. 관리자에게 배치 완료 알림을 발송한다

### 대체공휴일 계산 규칙

```
예시: 공휴일이 일요일인 경우
  1. 다음 월요일이 다른 공휴일인지 확인
  2. 아니면 → 다음 월요일이 대체공휴일
  3. 맞으면 → 화요일로 순차 이동 (연쇄 대체)
```

| 출력 | 설명 |
|------|------|
| DB 등록 | 해당 연도 법정+대체공휴일 전체 등록 |
| 배치 로그 | 처리 결과 로그 저장 |
| 관리자 알림 | 배치 완료/실패 알림 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 외부 API 호출 실패 | 내부 계산 로직으로 전환, 경고 로그 기록 |
| 내부 계산 오류 | 배치 중단, 관리자 알림 발송 + 오류 로그 |
| 이미 등록된 연도 재실행 | 기존 데이터 검증 후 변경분만 업데이트 (임시 공휴일은 보존) |
| 음력 변환 오류 | 해당 공휴일 건 건너뜀, 오류 로그 기록, 배치 계속 진행 |

연계 기능: HOL-004 (공휴일 데이터 소스 관리)

## HOL-002: 임시 공휴일 수동 등록 (관리자)

| 항목 | 내용 |
|------|------|
| **기능 ID** | HOL-002 |
| **기능명** | 임시 공휴일 수동 등록 |
| **설명** | 관리자가 정부 지정 임시 공휴일 또는 사내 지정 휴무일을 수동으로 등록한다. 등록된 임시 공휴일은 달력에 즉시 반영된다. |
| **사전조건** | - 관리자 권한으로 로그인<br>- 관리자 공휴일 관리 페이지 접근 |
| **입력값** | - 날짜 (필수)<br>- 공휴일 명칭 (필수, 최대 50자)<br>- 등록 사유 (선택, 최대 200자) |

### 처리 흐름

1. 관리자가 공휴일 관리 페이지에서 "임시 공휴일 추가" 버튼을 클릭한다
2. 등록 폼이 표시된다 (날짜, 공휴일 명칭, 사유 입력)
3. 관리자가 입력 후 저장을 클릭한다
4. 유효성 검사를 수행한다 (날짜 필수, 명칭 1~50자, 동일 날짜 중복 경고)
5. 저장이 완료되면 공휴일 목록과 달력 뷰에 즉시 반영된다
6. 등록 완료 메시지를 표시한다

### 등록 폼 구성

```
┌─────────────────────────────────────────────────┐
│  임시 공휴일 추가                                │
│                                                  │
│  날짜 *      [2026.05.11    📅]                  │
│  명칭 *      [_________________] (최대 50자)     │
│  사유        [_________________] (선택)          │
│                                                  │
│              [취소]  [저장]                      │
└─────────────────────────────────────────────────┘
```

### 중복 처리 정책

| 상황 | 처리 |
|------|------|
| 법정 공휴일과 동일 날짜 | 경고 팝업 "해당 날짜는 이미 법정 공휴일입니다. 그래도 추가하시겠습니까?" → 확인 시 중복 허용 |
| 임시 공휴일 중복 | 경고 팝업 표시 후 저장 허용 |

### 유효성 검사

| 필드 | 규칙 | 오류 메시지 |
|------|------|------------|
| 날짜 | 필수 | "날짜를 선택해주세요" |
| 날짜 | 오늘 이전 날짜 등록 시 | 경고만 표시, 저장 허용 |
| 명칭 | 필수, 1~50자 | "공휴일 명칭을 입력해주세요" |

| 출력 | 설명 |
|------|------|
| 달력 즉시 반영 | 등록 즉시 빨간 날짜 표시 |
| 공휴일 목록 갱신 | 관리자 목록에 추가 |
| 성공 알림 | 등록 완료 메시지 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 저장 실패 | 오류 메시지, 입력값 유지 |
| 권한 없는 사용자 접근 | 접근 거부, 등록 버튼 미표시 |

## HOL-003: 임시 공휴일 삭제 (관리자)

| 항목 | 내용 |
|------|------|
| **기능 ID** | HOL-003 |
| **기능명** | 임시 공휴일 삭제 |
| **설명** | 관리자가 등록된 임시 공휴일을 삭제한다. 법정/대체 공휴일은 이 기능으로 삭제할 수 없다. |
| **사전조건** | - 관리자 권한으로 로그인<br>- 삭제 대상이 임시 공휴일(`temporary`)인 것 |
| **입력값** | - 삭제할 공휴일 ID |

### 처리 흐름

1. 관리자가 공휴일 관리 목록에서 임시 공휴일 행의 "삭제" 버튼을 클릭한다
2. 삭제 확인 모달이 표시된다
3. "삭제" 확인 클릭 시 소프트 삭제가 수행된다 (비활성 처리 + 삭제 일시 기록)
4. 공휴일 목록 및 달력 뷰에서 즉시 제거된다
5. 삭제 완료 메시지를 표시한다

### 삭제 제한

| 구분 | 삭제 가능 여부 |
|------|---------------|
| 임시 공휴일 (`temporary`) | O (관리자만) |
| 법정 공휴일 (`statutory`) | X (삭제 버튼 미표시) |
| 대체 공휴일 (`substitute`) | X (삭제 버튼 미표시) |

> 법정/대체 공휴일 삭제가 필요한 경우, 관리자는 별도의 운영 절차를 통해 처리한다 (UI에서는 지원하지 않음).

### 삭제 확인 모달 구성

```
┌─────────────────────────────────────────────────┐
│  임시 공휴일 삭제                                │
│                                                  │
│  '임시 공휴일 (2026.10.02)'을 삭제하시겠습니까? │
│  달력에서 즉시 제거됩니다.                       │
│                                                  │
│              [취소]  [삭제]                      │
└─────────────────────────────────────────────────┘
```

| 출력 | 설명 |
|------|------|
| 목록에서 제거 | 관리자 목록 즉시 업데이트 |
| 달력에서 제거 | 해당 날짜 빨간 표시 제거 |
| 성공 알림 | 삭제 완료 메시지 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 이미 삭제된 공휴일 | "이미 삭제된 공휴일입니다" |
| 법정/대체 공휴일 삭제 시도 | 삭제 버튼 미표시, 시도 시 접근 거부 |
| 권한 없는 사용자 | 접근 거부, 삭제 버튼 미표시 |

## HOL-004: 공휴일 데이터 소스 관리

| 항목 | 내용 |
|------|------|
| **기능 ID** | HOL-004 |
| **기능명** | 공휴일 데이터 소스 관리 |
| **설명** | 법정 공휴일 자동 등록(HOL-001)에 사용되는 데이터 소스를 관리한다. 외부 공공 API와 내부 계산 로직의 우선순위 및 전환 정책을 정의한다. |
| **사전조건** | - 관리자 권한<br>- 외부 API 연동 설정 완료 |
| **입력값** | - 데이터 소스 우선순위 설정 (외부 API 우선 / 내부 계산 우선) |

### 데이터 소스 우선순위

```
기본 설정: 외부 API 우선

1순위: 외부 공공 API (공공데이터포털 특일정보 API)
         │
         ├─ 성공 → 데이터 사용
         │
         └─ 실패 (타임아웃 5초, 재시도 2회)
              │
              ▼
2순위: 내부 계산 로직 (전환)
         │
         └─ 실패 → 배치 중단, 관리자 알림
```

### 데이터 소스별 특성

| 소스 | 유형 | 갱신 주기 | 장점 | 단점 |
|------|------|-----------|------|------|
| 공공데이터포털 특일정보 API | 외부 API | 실시간 (연간 배치 호출) | 정확한 관보 기준 데이터 | 네트워크 의존, API 키 관리 필요 |
| 내부 계산 로직 | 코드 기반 | 배포 시 업데이트 | 오프라인 가능, 빠른 속도 | 법령 변경 시 수동 업데이트 필요 |

### 관리자 소스 설정 항목

| 설정 항목 | 설명 | 기본값 |
|-----------|------|--------|
| 데이터 소스 우선순위 | 외부 API 우선 / 내부 계산 우선 선택 | 외부 API 우선 |
| API 타임아웃 | 외부 API 응답 대기 시간 (초) | 5초 |
| API 재시도 횟수 | 실패 시 재시도 횟수 | 2회 |
| 마지막 배치 실행 결과 | 성공/실패 + 건수 표시 | — |
| 수동 배치 실행 | "지금 실행" 버튼 | — |

| 출력 | 설명 |
|------|------|
| 소스 설정 저장 | 다음 배치 실행 시 적용 |
| 배치 실행 결과 | 성공/실패 + 처리 건수 표시 |

### 예외 처리

| 상황 | 처리 |
|------|------|
| 외부 API 접속 정보 미설정 | 외부 API 소스 비활성화, 내부 계산 강제 사용, 관리자 경고 |
| 외부 API 응답 형식 변경 | 파싱 오류 로그 + 내부 계산 전환 |
| 내부 계산 로직 업데이트 필요 | 관리자 알림 (음력 오차 발생 시) |

연계 기능: HOL-001 (법정 공휴일 자동 등록)
