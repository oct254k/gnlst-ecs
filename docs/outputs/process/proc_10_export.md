# 엑셀 내보내기 프로세스 정의서

**관련 화면 명세**: [spec/13_export_responsive.md](../spec/13_export_responsive.md)

## PROC-EXP-001: 엑셀 다운로드 프로세스

### 개요

사용자가 리스트뷰에서 현재 적용된 필터 조건을 기준으로 일정 데이터를 엑셀 파일(`.xlsx`)로 내보내는 프로세스이다. 날짜 범위, 담당자, 키워드, @멘션 등 리스트뷰에 적용된 모든 필터 상태와 화면에 표시 중인 데이터를 그대로 사용하여 **클라이언트(브라우저)에서 직접 워크북을 생성**한다 (spec/13 EXP-001 기준). 서버 추가 요청 없이 즉시 다운로드되며, 파일명은 `일정_{filterLabel}_{YYYYMMDD}.xlsx` 형식이다.

### 참여자 (Actor)

| 구분 | 설명 |
|---|---|
| 사용자 | 엑셀 다운로드를 요청하는 로그인된 모든 사용자 |
| 리스트뷰 UI | 필터 상태와 다운로드 버튼을 제공하는 프론트엔드 컴포넌트 |
| 시스템 | 필터 조건에 따른 데이터 조회 및 엑셀 파일 생성 처리 |

### 사전 조건

- 사용자가 로그인 상태이며 일정 조회 권한이 있어야 한다.
- 리스트뷰에 최소 1건 이상의 조회 결과가 표시 중이어야 한다.
- 날짜 범위는 **선택**. 미설정 시 현재 적용된 필터(키워드·멘션·담당자·기간 일부)의 조회 결과 그대로 사용. 사용자가 명시 설정한 경우 최대 1년 상한.

### 트리거

리스트뷰 화면 우측 상단의 "엑셀 다운로드" 버튼 클릭.

### 메인 플로우

```mermaid
flowchart TD
    A([사용자: 엑셀 다운로드 버튼 클릭]) --> B[현재 리스트뷰 상태 사용\n- 적용 필터\n- 표시 중인 일정 목록]
    B --> C{조회 결과\n1건 이상?}
    C -- 0건 --> D[버튼 비활성 또는 안내\n다운로드할 데이터가 없습니다]
    C -- 1건 이상 --> E[건수 확인]
    D --> Z([프로세스 종료])
    E -- 1000건 초과 --> W[경고 안내\n데이터가 많아 생성에 시간이 걸릴 수 있습니다]
    W --> H
    E -- 1000건 이하 --> H[클라이언트: 표시 중인 일정 데이터를 13컬럼 구성으로 변환\n날짜·시각 포맷, 일정 유형 한글, 멘션 조인 등]
    H --> M[클라이언트: 엑셀 워크북 생성 - 일정 목록 시트]
    M --> N[헤더 행 13컬럼 추가\n날짜·시작·종료·시간대·유형·제목·임원·장소·회사·담당자·메모·등록자·등록일시]
    N --> O[데이터 행 순차 추가]
    O --> P[컬럼 너비 자동 조정 - 최대 내용 길이]
    P --> R[파일명 생성\n일정_{filterLabel}_{YYYYMMDD}.xlsx]
    R --> S[파일 생성 완료 - 브라우저 메모리]
    S --> T[브라우저 파일 자동 다운로드 - 서버 요청 없음]
    T --> V([다운로드 완료])
```

### 대안 플로우

| 상황 | 처리 방식 |
|---|---|
| 날짜 범위 미설정 | 현재 적용 필터(키워드·멘션·담당자)의 조회 결과를 그대로 다운로드 |
| 담당 임원 필터 없음 | 본인이 조회 가능한 모든 임원 일정 포함 |
| 멘션 필터만 적용된 경우 | 해당 멘션이 포함된 일정만 추출 |
| 1,000건 초과 | 경고 안내 "데이터가 많아 생성에 시간이 걸릴 수 있습니다" 후 진행 |

### 예외 플로우

| 예외 상황 | 처리 |
|---|---|
| 조회 결과 0건 | 버튼 비활성 또는 클릭 시 "다운로드할 데이터가 없습니다" 안내, 다운로드 차단 |
| 클라이언트 파일 생성 실패 (메모리·라이브러리 오류) | "파일 생성에 실패했습니다" 오류 안내, 콘솔 로그 |
| 날짜 범위 1년 초과 | "최대 1년 범위까지 다운로드 가능합니다" 안내 (날짜 범위 명시 설정 시) |
| 인증 만료 | 로그인 페이지로 이동 (다운로드 클릭 시점) |
| 모바일 브라우저 다운로드 | 일부 브라우저에서 파일 저장 위치 안내 메시지 추가 |

### 사후 조건

- `.xlsx` 파일이 브라우저에 의해 사용자 기기에 다운로드된다.
- 파일명은 `일정_{filterLabel}_{YYYYMMDD}.xlsx` 형식 (예: `일정_홍길동_20260511.xlsx`).
- 서버에는 어떠한 요청·파일도 발생하지 않는다 (클라이언트 단독 생성).

### 엑셀 출력 컬럼 정의 (13컬럼)

> spec/13 EXP-001 의 12컬럼 구성에 ERD 정합을 위해 `시간대`(`schedules.time_slot`) 1컬럼을 추가하여 총 13컬럼으로 확정.

| 순서 | 컬럼명 | 데이터 소스 | 형식 | 비고 |
|:---:|---|---|---|---|
| 1 | 날짜 | `schedules.schedule_date` | YYYY-MM-DD | 날짜 정렬 기준 |
| 2 | 시작 시각 | `schedules.start_time` | HH:mm | NULL이면 빈칸 |
| 3 | 종료 시각 | `schedules.end_time` | HH:mm | NULL이면 빈칸 |
| 4 | 시간대 | `schedules.time_slot` | 오전 / 점심 / 오후 / 저녁 / 종일 | Enum 한글 표시 (`morning`/`lunch`/`afternoon`/`evening`/`allday`) |
| 5 | 일정 구분 | `schedules.type` | 공통 / 개인 | `common`/`personal` 한글 |
| 6 | 제목 | `schedules.title` | 텍스트 | 1~200자 |
| 7 | 담당 임원 | `users.name` (`schedules.owner_id` 조인) | 텍스트 | 공통 일정이면 빈칸 또는 "공통" |
| 8 | 장소 | `schedules.location` | 텍스트 | 없으면 빈칸 |
| 9 | 회사 | `companies.name` (`mentions WHERE reference_type='company'` 조인) | 텍스트 | 복수 시 콤마 구분, 없으면 빈칸 |
| 10 | 담당자 | `contacts.name` (`mentions WHERE reference_type='contact'` 조인) | 텍스트 | 복수 시 콤마 구분, 없으면 빈칸 |
| 11 | 메모 | `schedules.memo` | 텍스트 | 없으면 빈칸 |
| 12 | 등록자 | `users.name` (`schedules.created_by` 조인) | 텍스트 | 대리 입력 시 실제 작성자 |
| 13 | 등록 일시 | `schedules.created_at` | YYYY-MM-DD HH:mm | KST |

### 연관 테이블

| 구분 | 상세 |
|---|---|
| 파일명 패턴 | `일정_{filterLabel}_{YYYYMMDD}.xlsx` (예: `일정_홍길동_20260511.xlsx`) |
| 조회 테이블 | 클라이언트 측 메모리 (이미 리스트뷰가 로드한 데이터). 조인 대상: `schedules`, `users`, `mentions`, `contacts`, `companies` |
| 최대 데이터 범위 | 사용자 명시 설정 시 1년 상한. 기본은 리스트뷰 필터에 따름. 1,000건 초과 시 경고 |
| 생성 위치 | **클라이언트(브라우저)** — 서버 요청·임시 파일 없음 |
