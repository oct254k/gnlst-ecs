# 공휴일 관리 화면설계서

- 화면 ID: SCR-ADMIN-HOLIDAY
- 관련 spec: [spec/08_holiday.md](../spec/08_holiday.md)
- 관련 process: [process/proc_08_holiday.md](../process/proc_08_holiday.md)
- 관련 ERD: `holidays`, `users`
- Phase: 2
- 최종 갱신: 2026-05-14

---

## 1. 개요

법정·대체·임시 공휴일을 통합 관리하는 관리자 전용 화면.

| 기능 | 화면 처리 |
|---|---|
| HOL-001 (법정 공휴일 자동 등록 배치) | **화면 없음**. 배치 결과만 본 화면 테이블에 표시 (`type='statutory'`/`'substitute'`, 등록자 "시스템") |
| HOL-002 (임시 공휴일 수동 등록) | `[BTN: + 임시 공휴일 추가]` → 등록 모달 |
| HOL-003 (임시 공휴일 삭제) | 행 액션 `[BTN: 삭제]` (`type='temporary'` 만 노출) → 삭제 확인 모달 |
| HOL-004 (데이터 소스 관리) | 페이지 하단 "데이터 소스 설정" 섹션 |

**권한**: `admin` 만 접근. `user` 는 사이드바 메뉴 미노출 + URL 직접 진입 시 `SCR-ERROR-403`.

### 3.6 상태별 와이어 (요약)

### 8.2 접근성

- `[TABLE]`: 정렬 헤더 `aria-sort`, 행 단위 `<tr>` 키보드 포커스 (Tab).
- `[MODAL]`: `role="dialog"`, `aria-modal="true"`, 포커스 트랩, `Esc` 닫기, 백드롭 클릭 닫기 (삭제 확인 모달은 백드롭 무시).
- `[DATE]`: 네이티브 `<input type="date">` 기본, 데스크톱 커스텀 캘린더 드롭다운 시 `aria-label="공휴일 날짜"`.
- `[TEXTAREA: 사유]`: 글자 수 카운터는 `aria-live="polite"`.
- `[TAG]`: 단순 시각 표시이므로 `aria-hidden="true"` (텍스트 컬럼이 의미 전달 — "유형" 컬럼에 텍스트가 함께 표기됨).
- `[BANNER: info]` "배치 실행 중": `role="status"`, `aria-live="polite"`.
- `[INLINE-ERROR]`: `aria-describedby` + `aria-invalid="true"`.
- 키보드: `Tab`/`Shift+Tab` 폼 순회, 모달 진입 시 첫 입력 자동 포커스.

## 9. 이슈 메모 (spec/process 검토 중 발견)

1. **`holidays.date` vs `holiday_date`** — `spec/08_holiday.md` 데이터 모델과 `proc_08_holiday.md` 본문이 `date` 컬럼으로 표기하나, `erd/erd.md` E08 의 컬럼명은 `holiday_date` 이다. 본 설계서는 ERD 기준 (`holiday_date`).
2. **`isActive` vs `is_active`** — spec/proc 는 카멜케이스 표기. ERD 는 snake_case `is_active`. 본 설계서는 ERD 기준.
3. **`type='legal'` 라벨 오류** — `proc_08_holiday.md` PROC-HOL-003 본문이 "법정 공휴일(`type = 'legal'`)" 로 표기. 실제 ERD enum 은 `statutory` (`erd/erd.md` E08 CHECK 제약). 본 설계서는 `statutory` 사용.
4. **HOL-004 데이터 소스 설정 메타 저장소** — 우선순위·타임아웃·재시도·마지막 배치 결과 등의 시스템 설정 항목은 ERD 의 어느 테이블에도 정의되어 있지 않다. 구현 시 시스템 설정 테이블(별도) 또는 환경 변수가 필요. 본 화면은 입력 UI 만 정의하며, 데이터 영속화 위치는 별도 라운드에서 결정.

상기 (1)(2)(3)은 spec/process 의 표기 오류로 보이며, 본 화면은 ERD SSOT 를 따른다 (작업지시서 §5.4).
