## 1. 레이아웃 슬롯 모델

본 시스템의 모든 인증 후 화면(대시보드 이하)은 4개의 슬롯 — **헤더(Header)**, **사이드바(Sidebar)**, **메인(Main)**, **푸터(Footer)** — 으로 구성된다. 인증 전 화면(로그인·비밀번호 찾기·재설정·초대 수락)은 헤더/사이드바/푸터를 제거한 **인증 전용 레이아웃(Auth Layout)** 을 사용한다.

### 1.1 슬롯 ID 표

| 슬롯 ID | 이름 | 역할 | 적용 화면군 |
|---|---|---|---|
| `SL-HEADER` | 헤더 (GNB) | 로고·사이드바 토글·알림·사용자 메뉴 | 인증 후 전체 |
| `SL-SIDEBAR` | 사이드바 (LNB) | 메뉴 트리, 권한별 노출 | 인증 후 전체 (모바일은 드로어) |
| `SL-MAIN` | 메인 컨텐츠 | 화면별 본문 | 전체 |
| `SL-FOOTER` | 푸터 | 버전·도움말·단축키 안내 | 인증 후 전체 (모바일은 생략 가능) |
| `SL-TABBAR` | 모바일 하단 탭바 | 핵심 5개 메뉴 | 모바일에서 `SL-SIDEBAR` 대체 |
| `SL-AUTH` | 인증 전용 본문 | 카드형 폼 1개 | `SCR-LOGIN`, `SCR-PASSWORD-FIND`, `SCR-PASSWORD-RESET`, `SCR-INVITE-ACCEPT`, `SCR-ERROR-403`, `SCR-ERROR-404` |
| `SL-OVERLAY` | 모달·패널·팝오버 오버레이 | 부모 화면 위 z-index | 모달·패널·팝오버 화면군 |

## 2. 브레이크포인트

본 작업지시서 §2.1 기준 3종을 정식 채택하되, `spec/13_export_responsive.md` RES-001 의 6단계는 화면별 디테일 적용 시 보조 단계로 참조한다.

| 코드 | 범위 (px) | 디바이스 | 컬럼 모델 |
|---|---|---|---|
| `BP-MOBILE` | 0 ~ 767 | 모바일 | 단일 컬럼, 사이드바는 드로어, 하단 `SL-TABBAR` |
| `BP-TABLET` | 768 ~ 1279 | 태블릿 | 사이드바 접힘(아이콘 only) + 본문, 상단 네비 보강 |
| `BP-DESKTOP` | 1280 이상 | 데스크톱 | 사이드바 펼침(고정 폭 240px) + 본문 |

### 2.1 RES-001 보조 구간 (참조)

| 보조 | 너비 | 차이점 |
|---|---|---|
| 소형 | 640+ | 여백 확장 (`BP-MOBILE` 내부) |
| 와이드 | 1536+ | 본문 최대 너비 `1440px` 로 캡 |

### 2.2 그리드

- 데스크톱·태블릿: **12 컬럼**, gutter 24px, 본문 max-width 1440px
- 모바일: **4 컬럼**, gutter 16px, 본문 좌우 padding 16px

## 3. 헤더 (`SL-HEADER`)

### 3.1 구성

```
┌─────────────────────────────────────────────────────────────────────┐
│ [☰] [LOGO 임원 일정]    [통합 검색* (Phase 2 보류)]    [🔔][🟢홍길동▾] │
└─────────────────────────────────────────────────────────────────────┘
```

| 영역 | 항목 | 동작 | 컴포넌트 ID |
|---|---|---|---|
| 좌측 | 사이드바 토글 `[☰]` | LNB 펼치기/접기 (`BP-DESKTOP`), 드로어 열기 (`BP-MOBILE`/`BP-TABLET`) | `[BTN: 사이드바 토글]` |
| 좌측 | 로고 `LOGO` | 클릭 시 `SCR-DASHBOARD` 이동 | `[LINK: 로고]` |
| 중앙 | 통합 검색 | **Phase 2 보류**. 1차 비노출 또는 비활성 placeholder | `[INPUT: 통합 검색 (Phase 2 보류)]` |
| 우측 | 알림 벨 `🔔` | 미확인 카운트 배지, 클릭 시 `SCR-NOTIFICATION` 드롭다운 | `[BTN-ICON: 알림 벨]` + `[BADGE: 미확인]` |
| 우측 | 사용자 아바타 | 드롭다운: 마이 페이지(`SCR-MY`), 로그아웃(`AUTH-004`) | `[DROPDOWN: 사용자 메뉴]` |

### 3.2 높이·고정

- 높이: 56px (모든 브레이크포인트 동일)
- `position: sticky; top: 0; z-index: 10`
- 스크롤 시 그림자(`box-shadow`) 활성화

### 3.3 권한별 헤더 차이

| 권한 | 헤더 표시 |
|---|---|
| 미인증 | 헤더 자체 미노출 (인증 레이아웃 사용) |
| 일반 임원 (`user`) | 알림 벨·사용자 메뉴 노출. 사용자 메뉴: 마이 페이지·로그아웃 |
| 관리자 (`admin`) | 동일. 사용자 메뉴에 "관리자 모드" 라벨 추가 (식별용) |

## 4. 사이드바 (`SL-SIDEBAR`)

### 4.1 메뉴 트리 (`ia/ia.md` §6.2 권한 매트릭스 기준)

```
일정
├─ 대시보드        SCR-DASHBOARD     (user, admin)
├─ 달력            SCR-CALENDAR      (user, admin)
└─ 리스트          SCR-LIST          (user, admin)

협업
└─ 모임 레이더     SCR-RADAR         (user, admin)  ※ Phase 3

데이터
├─ 연락처          SCR-CONTACT       (admin 메뉴 노출, user 는 직접 URL/멘션 진입 시 조회 전용)
└─ 회사            SCR-CONTACT-COMPANY (동상)

관리자                                ※ admin 만 그룹 자체 노출 (PERM-004)
├─ 사용자 관리     SCR-ADMIN-USER
├─ 대리권한 관리   SCR-ADMIN-PROXY    ※ Phase 2
├─ 공휴일 관리     SCR-ADMIN-HOLIDAY  ※ Phase 2
└─ 알림 발송 이력  SCR-ADMIN-NOTIFICATION-LOG ※ Phase 2
```

### 4.2 브레이크포인트별 사이드바

| 브레이크포인트 | 사이드바 표시 |
|---|---|
| `BP-DESKTOP` | 고정 폭 240px, 메뉴명+아이콘. 토글 시 60px(아이콘 only) 로 접힘 |
| `BP-TABLET` | 기본 접힘(60px), 토글 시 240px 오버레이 |
| `BP-MOBILE` | 미노출. `[☰]` 클릭 시 좌측 드로어로 슬라이드. `SL-TABBAR` 가 주 네비 |

### 4.3 빠른 액션 (사이드바 하단)

| 액션 | 컴포넌트 | 노출 조건 |
|---|---|---|
| `[BTN: + 일정 등록]` | 1차 액션 (Primary) | 인증 후 전체 |
| `[BTN: + 공통 일정 등록]` | 2차 액션 | 인증 후 전체 (`user`/`admin`) |
| `[BTN: + 사용자 초대]` | 2차 액션 | `admin` 만 |

### 4.4 권한별 사이드바 노출 매트릭스

| 메뉴 그룹 | `user` | `admin` |
|---|:-:|:-:|
| 일정 (전체) | ✅ | ✅ |
| 협업 (모임 레이더) | ✅ | ✅ |
| 데이터 (연락처·회사) | ❌ (메뉴 미노출) | ✅ |
| 관리자 (4개) | ❌ (그룹 자체 미노출) | ✅ |

> `user` 가 `/연락처` URL 또는 멘션 칩에서 진입한 경우, 화면은 조회 전용으로 렌더링한다 (PERM-004, `ia.md` §4 비고).

## 8. 인증 전용 레이아웃 (`SL-AUTH`)

### 8.1 적용 화면

- `SCR-LOGIN`, `SCR-PASSWORD-FIND`, `SCR-PASSWORD-RESET`, `SCR-INVITE-ACCEPT`
- 에러 페이지(`SCR-ERROR-403`, `SCR-ERROR-404`) 도 동일 레이아웃 사용 (단, 인증 후 진입 시 헤더 유지)

### 8.2 구조

```
┌─────────────────────────────────────────┐
│                                         │
│           ┌─────────────────┐           │
│           │   [LOGO]        │           │
│           │   임원 일정     │           │
│           │                 │           │
│           │   (폼 본문)     │           │
│           │                 │           │
│           │   [BTN: 1차]   │           │
│           │   [LINK: 보조] │           │
│           └─────────────────┘           │
│                                         │
│         v0.1.0  ·  도움말  ·  ?         │
│                                         │
└─────────────────────────────────────────┘
```

- 카드 폭: 데스크톱 400px, 모바일 100% (좌우 16px padding)
- 배경: 그라데이션 또는 단색
- 헤더/사이드바/푸터 모두 미노출

## 9. 모달·패널·팝오버 오버레이 (`SL-OVERLAY`)

### 9.1 종류와 표시 정책

| 종류 | 데스크톱 | 모바일 | 예시 화면 |
|---|---|---|---|
| 모달 (Modal) | 중앙 정렬, max-width 640px, 배경 어둡게 | 전체 화면 모달 (`fullscreen`) | `SCR-MODAL-SCHEDULE-FORM`, `SCR-MODAL-SCHEDULE-DETAIL`, `SCR-MODAL-CONFIRM-DELETE`, `SCR-MODAL-AUDIT-LOG`, `SCR-MODAL-MENTION-NEW-CONTACT` |
| 사이드 패널 (Panel) | 우측 슬라이드인, 폭 400px | 전체 화면 모달 | `SCR-PANEL-DAY-DETAIL` |
| 팝오버 (Popover) | 트리거 위치 기준, max-width 360px | 바텀시트로 자동 전환 (RES-001) | `SCR-POPOVER-RELATIONSHIP` |

### 9.2 z-index 스택

```
z-index 50: 토스트 (Toast)
z-index 40: 팝오버 (Popover)
z-index 30: 사이드 패널 (Panel)
z-index 20: 모달 (Modal) + 백드롭
z-index 10: 헤더 (Header)
z-index  9: 모바일 탭바 (Tabbar)
z-index  1: 사이드바 펼침 오버레이 (BP-TABLET)
```

### 9.3 모달 공통 구조

```
┌──────────────────────────────────┐
│ [화면 제목]                  [×] │
├──────────────────────────────────┤
│                                  │
│ (모달 본문 — 폼/상세/확인 등)    │
│                                  │
├──────────────────────────────────┤
│              [BTN: 취소][BTN: 확인]│
└──────────────────────────────────┘
```

- ESC / 백드롭 클릭 → 닫기 (단, 확인 모달은 백드롭 클릭 무시)
- 포커스 트랩(focus trap) 적용
